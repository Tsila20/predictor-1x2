# ⚽ French Virtual League Predictor

AI-based football predictor using historical CSV data.

## 📊 Features

- 1X2 Prediction (Home / Draw / Away)
- G/NG Prediction
- Exact Score estimation
- Historical data analysis
- Mobile responsive UI
